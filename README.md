# Hacktoberfest 2026

My projects for the Hacktoberfest 2026 Open-Source AI DEV Challenges. Each week is a new project in its own folder, built during that week's challenge period. Everything runs locally with open-weight models (Gemma through Ollama), so it works with no internet and keeps data on your own computer.

By Haoua Tamaivou, computer engineering student (network engineering), studying cybersecurity, from Cameroon.

## Projects

| Week | Theme | Project | What it does |
|------|-------|---------|--------------|
| 2 | Side Hustle | [Offline Listing Writer](week-2-offline-listing-writer) | Writes WhatsApp, Facebook and Instagram product listings for small sellers in French or English, offline. |
| 3 | Slow and Steady | [Lazy Study Buddy](week-3-lazy-study-buddy) | Turns pasted study notes into a short summary and quiz questions, offline. |

## Common setup

1. Install [Ollama](https://ollama.com).
2. Download a model once (needs internet): `ollama pull gemma3:4b`
3. Open the folder of the project you want and follow its README.
